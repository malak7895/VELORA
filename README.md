✨ مشروع VELORA

  هو مشروع واجهة متجر إلكتروني للأزياء تم تطويره باستخدام HTML5 وCSS3، بهدف تصميم موقع حديث وأنيق مستوحى من أشهر متاجر الملابس العالمية.

مميزات المشروع
🏠 الصفحة الرئيسية (Home).
                                                                                                                                🆕 صفحة أحدث المنتجات (New Arrivals)🆕
👗 قسم الملابس النسائية (Women).
👔 قسم الملابس الرجالية (Men).
👜 صفحة Collection تضم الملابس والإكسسوارات والحقائب والأحذية.
🔥 صفحة Sale تعرض المنتجات المخفضة مع الأسعار قبل وبعد الخصم.
📞 صفحة Contact للتواصل.

                                                                                                                                         5-Git & GitHub
الهدف من المشروع

تطبيق أساسيات تطوير واجهات الويب من خلال تصميم متجر إلكتروني منظم واحترافي، مع التركيز على:

تنظيم الصفحات وربطها ببعض.
تصميم واجهة مستخدم بسيطة وأنيقة.
استخدام Flexbox لترتيب العناصر.
إنشاء بطاقات منتجات (Product Cards).
إضافة تأثيرات Hover وحركات انتقالية (Transitions).
تحسين تجربة التصفح وسهولة التنقل بين الصفحات.
